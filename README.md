# Private — 어드민 웹페이지 디자인

회사 어드민 웹페이지의 디자인 작업 저장소입니다.

## 목적
- 집(서브 기기)과 회사(메인 기기) 양쪽에서 이어서 작업하기 위한 저장소
- Claude Code의 원격(클라우드) 작업 및 `git pull` 기반 동기화에 사용

## 작업 방식
- 집에서 작업 → `commit` → `push`
- 회사에서 `git pull` 로 이어서 작업 (또는 원격 작업으로 진행)

## 구조 (예정)
- `docs/` — 디자인 문서
- `tokens/` — 컬러/타이포/스페이싱 등 디자인 토큰
- `images/` — 컴포넌트·화면 시안
