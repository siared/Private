# 클래스 제작 현황 트래킹

관리자가 크리에이터들의 클래스 제작(계약→커리큘럼→촬영→편집→검수→오픈)을 트래킹하고,
더딘 크리에이터를 찾아 컨택하는 화면. `index.html` 단일 파일 목업 (목록 ↔ 상세 전환 동작).

## 지원 업무
1. 전체 성과(무사히 완성까지) — 통계 바(제작 중/오픈 완료/완주율/지연) + 완주 퍼널
2. 내 담당 크리에이터 성과 — 필터 칩 [담당 매니저 ▾] 선택 시 통계·퍼널·테이블 전체 재계산
3. 재촉·응답 히스토리 — 행 클릭 → 상세의 컨택 히스토리 타임라인(재촉/응답/무응답 경고/메모)

## 산출물 표기 (CLAUDE.md 규칙)

사용한 페이지 타입·폭 패턴:
- **목록 화면**: `1열 full-width` — 페이지 헤더 86 → 통계 바 → 테이블 블록(검색/필터 칩/테이블/푸터, 내부 간격 12)
- **상세 화면**: `2열 4:8` (max-1312 중앙) — 좌 요약 카드 스택(기본 정보·제작 정보·활동 채널) / 우 컨택 히스토리(상태 카드 + 타임라인)
- 셸: 헤더 72 풀폭 + 사이드바 240(흰 배경, 활성 #F3F3F3) + 콘텐츠 좌우 패딩 40
- 토큰: `tokens/tokens.md` 그대로 (primary #FF5D00, Pretendard JP, 헤어라인+radius 16, 인풋/버튼 38, 행 ~53)
