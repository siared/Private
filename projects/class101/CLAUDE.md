# CLASS101 하위 프로젝트 규칙

이 디렉토리 아래는 전부 클래스101 어드민 관련 프로젝트다. 프로젝트마다 폴더 하나
(`projects/class101/<프로젝트명>/`)를 만들어 작업한다.

## 필수 적용

여기서 화면을 디자인·구현할 때는 **예외 없이** 저장소 루트의 두 문서를 먼저 읽고 따른다:

1. `docs/layout-patterns.md` — 셸 구조(헤더 72 / 사이드바 240 / 콘텐츠 패딩 40),
   콘텐츠 폭 패턴 5종, 목록·폼·상세 페이지 골격
2. `tokens/tokens.md` — 컬러(primary #FF5D00)·타이포(Pretendard JP)·radius·스페이싱

사용자가 템플릿 이미지를 주지 않아도, 프로젝트 목적 설명만으로 위 골격에 맞춰 작업한다.

## 페이지 타입 매핑 (요약)

- 테이블 목록 → `1열 full-width` (콘텐츠 1600)
- 입력 폼 → `1열 max-720` (콘텐츠 640, 저장/취소는 페이지 헤더 우측)
- 상세 페이지 → `2열 4:8` (좌 요약 카드 384 / 우 메인 808)
- 그 외 일반 → `1열 max-1312`

## 산출물 표기

- 결과물(HTML 목업, 컴포넌트 등)에 어떤 페이지 타입·폭 패턴을 썼는지 명시한다.
- 문서에 없는 값이 필요해 임의로 정했다면 그 값과 근거를 결과물에 함께 적는다.
