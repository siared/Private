# 화면 타입 3종 — 완성 골격

출처: Figma 섹션 "화면 타입별 활용 예시" (node `14919:102422`).
예시 프레임 노드: 목록 `14919:112129` · 입력 폼 `14919:112213` · 상세 `14919:112311`.
새 화면은 이 셋 중 가장 가까운 타입을 골라 골격을 유지한다. 셸(헤더/사이드바)은 공통.

## 1. 목록 / 대시보드 — `1열 full-width` (콘텐츠 1600)

```
Admin Page Header (제목 + 우측 버튼 2~3개, CTA 맨 오른쪽)   h≈86, 컨테이너 상단에서 20 내려 시작
Stats Bar                                                 h=90
  ├ Time Picker (기간 선택)  w=122
  └ 지표 카드 × 4  균등 분할(각 ≈370), 카드 사이 세로 Divider
      카드: 패딩 16, 내부 gap 8
      라벨  Body.level3 13/18 Medium
      수치  Title.level3 24/32 Bold  (예: "100건")
── 간격 28 ──
Table [@vibrant-ui]  w=1600
  ├ 검색&액션 행   h=38 : 검색 TextField 400×38 좌측 + 우측 buttonsSection(옵션)
  ├ (간격 12)
  ├ 필터 행       h=38 : Filter Chip Group 좌측 + 우측 보기 옵션
  ├ (간격 12)
  ├ 테이블 섹션    : 헤더 행 44 + 데이터 행 44 × n (기본 10행)
  └ 푸터          h=38 : 좌측 총 건수, 우측 페이지네이션
```

- Stats Bar가 불필요한 단순 목록이면 생략하고 Page Header → Table로 바로 간다.
- 테이블은 vibrant-ui Table 컴포넌트(검색/필터/페이지네이션 내장)를 쓴다. 직접 만들지 않는다.

## 2. 입력 폼 — `1열 max-720` (콘텐츠 640)

```
Admin Page Header : ← back(30) + 제목, 우측 [취소 tertiary] [저장/등록 primary]   h≈86
폼 카드 스택 (카드 간 28)
  카드 = List Header(58: 섹션 제목 14/18 Bold) + 폼 바디(패딩 20)
    행: Label(top) + TextField lg(50) = 74, 행 간 16
    다열 분할: 2열 294×2 / 3열 192×3 / 4열 141×4 (gap 12, 콘텐츠 600 기준)
```

- 좁은 폭(640)이 의도된 값이다 — 폼을 넓히려고 max-1312로 올리지 않는다.
  필드가 많으면 카드(섹션)를 나눠 세로로 쌓는다.
- 저장/취소는 페이지 헤더 우측에 둔다. 폼 하단 고정 버튼 바는 이 패턴에 없다(필요 시 예외 보고).

## 3. 상세 페이지 — `2열 4:8` (콘텐츠 1232)

```
Admin Page Header : ← back + 제목 + 라벨(옵션), 서브타이틀     h=98, 본문과 간격 16
                    우측 [버튼 tertiary ×2] [CTA primary]
┌ 좌측 보조 컬럼 (기준 384, 예시 실측 420) ┐  ┌ 우측 주 컬럼 (기준 808, 예시 실측 772) ┐
│ 요약/기본 정보 카드 스택 (카드 간 20)     │  │ 섹션 헤더: 제목 Title.level5 18/22 Bold │
│  카드 = List Header(58, 우측 Ghost      │  │           + 우측 OutlinedButton md     │
│         Button sm 옵션)                 │  │ ── 간격 16 ──                          │
│       + List.Item 36 × n (px12 pb12)   │  │ 탭 또는 자유 콘텐츠 슬롯                 │
└─────────────────────────────────────────┘  └────────────────────────────────────────┘
                 컬럼 gap 40
```

- 좌측 = 읽기 전용 요약(기본 정보, 상태, 메타), 우측 = 주 작업 영역(탭, 테이블, 편집 폼 등).
- 좌/우 폭은 384/808이 기준이지만 Figma 예시 자체가 420/772를 쓴다.
  합계 1232·gap 40을 지키는 범위에서 보조 컬럼 384~420은 자유 조정, 그 밖은 예외 보고.
- **상세 페이지는 예외가 가장 자주 필요한 타입이다.** 콘텐츠가 2열에 맞지 않으면
  1열 max-1312로 대체하는 것까지는 가까운 패턴 선택으로 허용되지만,
  그 외 구조 변경(3열, 비대칭 폭, full-width 상세 등)은 SKILL.md의 예외 프로토콜을 따른다.
