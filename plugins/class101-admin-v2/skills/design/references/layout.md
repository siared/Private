## 2. 콘텐츠 폭 패턴 5종

| # | 패턴 | 컨테이너 | 콘텐츠 폭 | 컬럼 구성 | 주 용도 |
|---|---|---|---|---|---|
| 1 | 1열 full-width | 1680 (영역 전체, 가변) | 1600 | 단일 | 테이블 목록, 대시보드 |
| 2 | 1열 max-1312 | max-width 1312, 중앙 | 1232 | 단일 | 일반 콘텐츠 |
| 3 | 1열 max-720 | max-width 720, 중앙 | 640 | 단일 | 입력 폼 |
| 4 | 2열 8:4 | max-width 1312, 중앙 | 1232 | 주 808 + gap 40 + 보조 384 | 메인+사이드 정보 |
| 5 | 2열 4:8 | max-width 1312, 중앙 | 1232 | 보조 384 + gap 40 + 주 808 | 상세 페이지 |

검산 (1920 뷰포트):
- 콘텐츠 영역 1680 = 1920 − 240(사이드바)
- full-width 콘텐츠 1600 = 1680 − 40×2
- max-1312 좌우 여백 184 = (1680 − 1312) / 2, 콘텐츠 1232 = 1312 − 40×2
- max-720 좌우 여백 480 = (1680 − 720) / 2, 콘텐츠 640 = 720 − 40×2
- 2열: 808 + 40 + 384 = 1232 (주:보조 ≈ 2:1, Figma 명명은 8fr:4fr)

박스 모델 해석:
- 컨테이너는 `max-width` + 좌우 `margin: auto`(중앙 정렬), full-width는 flex로 영역을 채운다.
- 뷰포트가 1920보다 좁으면 컨테이너가 max-width 이하로 줄고, 패딩 40과 컬럼 gap 40은 유지한다.
- 2열의 보조 컬럼(384)은 고정에 가깝게, 주 컬럼(808)이 신축한다.

## 3. 페이지 헤더 (Admin Page Header)

콘텐츠 폭 전체를 차지하며 본문 카드 스택 위에 놓인다.

- 상하 패딩 20 (좌우 0 — 콘텐츠 폭에 이미 정렬됨). 기본 전체 높이 86.
- 좌측 제목: Title.level4 — 20px / line-height 26 / Bold / `onView1`(#0C0C0C).
- 우측 버튼 그룹: gap 8, ContainedButton md(높이 38). 보조 버튼은 `tertiary`,
  주 CTA는 `primary`(#FF5D00)로 **맨 오른쪽**. 버튼 0~3개.
- 변형 — 뒤로가기/서브타이틀 (폼·상세 페이지):
  - 제목 왼쪽에 back 버튼(30×30), 제목 옆 메타데이터(옵션).
  - 제목 아래 서브타이틀(캡션, `onView3`) 추가 시 전체 높이 98, 본문과의 간격 16.

## 4. 카드 (List 카드) — 본문의 기본 단위

본문 콘텐츠는 카드의 수직 스택으로 구성한다.

- 스타일: 배경 `background`(#FFF), 보더 1px `outline2`(rgba(0,0,0,0.1)), radius `md`(8).
- 카드 간 수직 간격: **기본 24** (토큰 `Layout/Responsive Gap/between-card-lg`).
  Figma 실측 허용 범위 20~28 — 패턴 프레임은 28, 밀도 높은 상세 예시는 20을 쓴다.

### 카드 헤더 (List Header [@vibrant-ui])
- 패딩 20 (전방향), 높이 58.
- 제목: Title.level7 — 14px / 18 / Bold / `onView1`. 아래 설명(옵션): Body.level4 12px / `onView3`.
- 우측 버튼 그룹(옵션): GhostButton sm, gap 16.

### 카드 바디 A — 폼 (Form Group Row)
- 패딩 20 (전방향).
- 행 = vibrant-ui `Label`(alignment="top") + `TextField`(size="lg", 높이 50).
  라벨 18 + 간격 6 + 필드 50 = 행 높이 74.
- 행 간 수직 간격 16.
- 한 행을 2/3/4열로 분할 가능 — 컬럼 gap 12, 균등 분할.
  (예: 콘텐츠 600일 때 2열 294×2, 3열 192×3, 4열 141×4)

### 카드 바디 B — 읽기 전용 리스트 (List Item Group)

- vibrant-ui `List.Item` 높이 36 (라벨 좌 / 값 우), 간격 없이 연속 배치.
