## 1. 전체 셸 (App Shell)

```
┌────────────────────────────────────────────────┐
│ 헤더 72px (풀폭) — 좌: 토글·로고 / 우: 스토어·상태·아바타 │
├─────────┬──────────────────────────────────────┤
│ 사이드바   │  콘텐츠 영역 1680px (좌우 패딩 40px)       │
│ 240px    │  ┌ 페이지 헤더 86px                      │
│ (흰 배경)  │  └ 본문                                │
└─────────┴──────────────────────────────────────┘
```

| 항목 | 값 |
|---|---|
| 기준 뷰포트 | 1920px |
| 헤더 | 높이 72px, **풀폭**(사이드바 위가 아니라 화면 전체). 흰 배경 + 하단 헤어라인 |
| 사이드바 | 폭 240px, 헤더 아래 좌측 고정. **흰 배경**(다크 아님) + 우측 헤어라인 |
| 콘텐츠 영역 | 1680px (1920−240), 좌우 패딩 40px (`Layout/Content Area/Padding X`) |

사이드바 메뉴: 섹션 라벨(12px 회색, 높이 40px) + 아이템(높이 44px, 아이콘 20×20 + 라벨 14px).
활성 항목은 연회색(#F3F3F3) 라운드 하이라이트.

## 2. 콘텐츠 폭 패턴 5종

본문 골격은 반드시 아래 5종 중 하나를 쓴다. 임의로 새 폭을 발명하지 않는다.

| 패턴 | ContentsArea | 실제 콘텐츠 폭 | 주 용도 |
|---|---|---|---|
| 1열 full-width | 1680 (전체) | 1600 | 테이블 목록 |
| 1열 max-1312 | 1312, 중앙 정렬 | 1232 | 일반 콘텐츠 |
| 1열 max-720 | 720, 중앙 정렬 | 640 | 입력 폼 |
| 2열 8:4 | 1312, 중앙 정렬 | 808 + 거터 40 + 384 | 메인 + 보조 패널 |
| 2열 4:8 | 1312, 중앙 정렬 | 384 + 거터 40 + 808 | 요약 + 메인 (상세 페이지) |

- 좌우 패딩 40은 ContentsArea 폭 **안쪽**에 포함된다. CSS 기준:
  `max-width: 1312px; margin: 0 auto; padding: 0 40px; box-sizing: border-box`
- 검산: full-width 40+1600+40=1680 / max-1312 40+1232+40=1312 / max-720 40+640+40=720 /
  2열 40+808+40(거터)+384+40=1312
- 카드(섹션) 간 세로 간격: 28px

## 3. 페이지 헤더 (공통)

- 높이 86px, 콘텐츠 최상단. 좌측: (하위 페이지면) ← 뒤로가기 + 타이틀 20px Bold / 우측: 버튼 그룹
- primary(오렌지 필) 버튼은 화면당 최대 1개, 나머지는 아웃라인
- 폼 화면의 저장/취소도 여기 우측에 배치한다 (하단 고정 액션바를 쓰지 않는다)

## 4. 페이지 타입 → 폭 패턴 매핑

| 페이지 타입 | 폭 패턴 | 골격 한 줄 |
|---|---|---|
| 목록 (테이블) | `1열 full-width` | 페이지 헤더 → (통계 스트립) → 테이블 블록(검색·필터·테이블·푸터, 내부 간격 12) |
| 입력 폼 | `1열 max-720` | 페이지 헤더 → 섹션 카드 스택 (간격 28) |
| 상세 | `2열 4:8` | 페이지 헤더 → 좌 요약 카드 스택 / 우 메인 콘텐츠 |
| 대시보드 | 전용 없음 | 통계 스트립 + 필요시 `2열 8:4`. 신규 구성은 사용자에게 확인 |
| 그 외 일반 | `1열 max-1312` | — |

각 타입의 세부 구성(카드·셀·필드·타임라인 등)은 화면 목적에 맞게 정한다.
Figma 활용 예시에서 실측한 세부 기록은 `docs/reference-examples.md` 참고 (강제 아님).

## 5. 공통 스타일 원칙

- **플랫 & 뉴트럴**: 전체가 흰 배경. 카드는 그림자 없이 헤어라인 아웃라인 + radius 16
- **primary 오렌지(#FF5D00)는 화면당 핵심 CTA 1개에만**. 나머지는 아웃라인 버튼
- 상태 표현: 색 점 + 텍스트 라벨 동반 (색만으로 구분하지 않음)
- 개인정보(이름·이메일·전화)는 기본 마스킹, "마스킹 해제" 액션으로 노출
