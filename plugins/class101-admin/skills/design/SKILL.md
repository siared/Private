# CLASS101 어드민 디자인 스킬

CLASS101 Admin Figma에서 실측 추출한 레이아웃 패턴과 디자인 토큰을 적용한다.
목적은 강제가 아니라 **패턴화** — 웬만한 상황에서는 지켜서 유저에게 익숙한 UX를 주고
효율적으로 작업하기 위함이다. 화면 특성상 벗어나는 게 나으면 벗어나되 이유를 결과물에 명시한다.
**가이드의 범위는 레이아웃 구조와 UI 스타일**(치수·패딩·radius·테두리·타이포)까지이고,
그 틀에 담을 내용물(데이터·기능·셀 구성)은 화면 목적에 맞게 정한다.

## 1단계: 상세 스펙 읽기

이 스킬 디렉토리의 `references/` 아래 두 파일이 단일 진실 공급원(source of truth)이며,
아래 요약과 다르면 파일 쪽을 따른다:

- `references/layout-patterns.md` — 셸 구조, 콘텐츠 폭 패턴 5종,
  **페이지 타입별 골격 + UI 스타일 실측** (통계 바/테이블 블록/폼 카드/상세 2열)
- `references/tokens.md` — 컬러/타이포/radius/스페이싱 토큰

(원본은 siared/Private 저장소의 `docs/`·`tokens/`이며 이 사본은 스크립트로 동기화된다.
실제 화면에서 내용물을 응용한 맥락은 저장소의 `docs/reference-examples.md` 참고 — 강제 아님.)

## 2단계: 핵심 규칙 (요약)

**셸**: 풀폭 헤더 72px(흰 배경) → 그 아래 좌측 사이드바 240px(흰 배경, 활성 메뉴는
#F3F3F3 라운드 하이라이트) + 콘텐츠 영역(좌우 패딩 40px). 기준 뷰포트 1920px.

**콘텐츠 폭 패턴 5종** (특별한 이유 없이 새 폭을 만들지 않는다):
| 패턴 | 콘텐츠 폭 | 용도 |
|---|---|---|
| 1열 full-width | 1600 | 대시보드 테이블 리스트 |
| 1열 max-1312 | 1232 | 일반 |
| 1열 max-720 | 640 | 입력 폼 |
| 2열 8:4 | 808+40+384 | 메인+보조 |
| 2열 4:8 | 384+40+808 | 상세(요약+메인) |

**페이지 헤더**: 상하 패딩 20(실측 전고 86), 좌측 ← IconButton sm + 타이틀 20/26 Bold,
우측 ContainedButton md 그룹(gap 8). primary(#FF5D00)는 화면당 최대 1개.
**폼의 저장/취소도 여기 배치 (하단 액션바 금지)**.

**스타일**: Pretendard JP, 본문 14px. 그림자 없음. 카드 테두리 outline2(rgba(0,0,0,0.1)),
내부 구분선 outline1(0.05). radius — 콘텐츠 섹션 카드 16 / 정보 카드·통계 바 8 / 인풋·버튼 8.
인풋·버튼·필터 칩 높이 38, 테이블 행 44. 상태는 색 점+텍스트 라벨 동반.

## 3단계: 작업 시 명시할 것

- 사용한 페이지 타입과 폭 패턴을 결과물에 명시
- 문서에 없는 값을 임의로 정했으면 값과 근거를 명시하고, 반복될 값이면
  siared/Private의 `docs/`·`tokens/` 반영을 사용자에게 제안
