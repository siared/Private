# CLASS101 어드민 디자인 스킬

CLASS101 Admin Figma에서 실측 추출한 레이아웃 패턴과 디자인 토큰을 적용한다.

## 1단계: 원본 문서 읽기

이 스킬이 있는 저장소(Private)의 루트에서 다음 두 파일을 읽는다. 이 파일들이
단일 진실 공급원(source of truth)이며, 아래 요약과 다르면 파일 쪽을 따른다:

- `docs/layout-patterns.md`
- `tokens/tokens.md`

## 2단계: 핵심 규칙 (요약)

**셸**: 풀폭 헤더 72px(흰 배경) → 그 아래 좌측 사이드바 240px(흰 배경, 활성 메뉴는
#F3F3F3 라운드 하이라이트) + 콘텐츠 영역(좌우 패딩 40px). 기준 뷰포트 1920px.

**콘텐츠 폭 패턴 5종** (임의 레이아웃 발명 금지):
| 패턴 | 콘텐츠 폭 | 용도 |
|---|---|---|
| 1열 full-width | 1600 | 테이블 목록 |
| 1열 max-1312 | 1232 | 일반 |
| 1열 max-720 | 640 | 입력 폼 |
| 2열 8:4 | 808+40+384 | 메인+보조 |
| 2열 4:8 | 384+40+808 | 상세(요약+메인) |

**페이지 헤더**: 높이 86px, 좌측 ←+타이틀(20px Bold), 우측 버튼 그룹.
primary(#FF5D00) 버튼은 화면당 1개. **폼의 저장/취소도 여기 배치 (하단 액션바 금지)**.

**스타일**: Pretendard JP, 본문 14px. 카드는 그림자 없이 헤어라인(rgba(0,0,0,0.05))
아웃라인 + radius 16. 인풋/버튼 radius 8, 높이 38px. 상태는 색 점+텍스트 라벨 동반.

## 3단계: 작업 시 명시할 것

- 사용한 페이지 타입과 폭 패턴을 결과물에 명시
- 문서에 없는 값을 임의로 정했으면 값과 근거를 명시하고, 반복될 값이면
  `docs/`·`tokens/` 반영을 사용자에게 제안
