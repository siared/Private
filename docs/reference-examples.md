# 내용물 응용 맥락 기록 (참고용 — 강제 아님)

가이드(`docs/layout-patterns.md`)가 정한 레이아웃·UI 스타일 틀 위에, 실제 화면에서
**내용물을 어떻게 디자인했는지**의 맥락을 쌓아두는 문서다. 규칙이 아니라 전례(前例)이며,
비슷한 상황을 만났을 때 "그때 이렇게 풀었더라"를 떠올리는 용도로만 쓴다.
치수·스타일 값은 여기 적지 않는다 — 그건 가이드와 토큰 문서의 몫.

---

## 크리에이터 소싱 관리 (2026-07, 목록·폼·상세 3화면)

**목록 — 상태 중심 운영 테이블**
- 행마다 진행 상태를 "색 점 + 라벨 + ▾" 셀렉트 셀로 넣어 테이블에서 바로 상태를 바꾸게 함
- 외부 채널 정보는 태그 칩으로 압축 ("Youtube 32k" + "+2" 식으로 넘치는 건 +N 처리)
- 기한 초과 같은 경고는 연빨강 배경 + 빨강 텍스트 뱃지 ("3개월+ 지남")를 셀 안에 병기
- 값이 없는 셀은 회색 "없음" 텍스트로 통일

**입력 폼 — 반복·복합 입력의 처리**
- 여러 개 입력받을 수 있는 필드(이메일 등)는 인풋 아래 "+ 추가" 텍스트 버튼으로 반복
- 전화번호는 3분할 인풋, 카테고리는 1차/2차/3차 캐스케이드 컬럼 셀렉터로 풀었음
- 담당자 지정은 "나에게 할당" 칩 버튼 + 검색 아이콘 버튼 조합
- 항목이 쌓이는 섹션은 카드 타이틀에 카운트("활동 채널 (0)") + 우측 "+ 추가" 버튼

**상세 — 요약 카드와 히스토리**
- 개인정보(이름·이메일·전화)는 기본 마스킹하고 카드 헤더의 "마스킹 해제" 유틸 액션으로 노출
- 좌측 요약 카드는 라벨:값 행 반복. 값이 여러 개면 세로로 쌓고 "대표" 같은 칩을 동반
- 연관 엔티티(활동 채널 등)는 링크 + 캡션(팔로워 수) + 외부링크 아이콘 행으로,
  빈 카드는 회색 한 줄("연결된 계정 없음") + 헤더에 연결 액션
- 우측 메인은 컨택 히스토리 타임라인: 파란 점 + 세로 연결선, 항목마다
  유형 칩(이메일/전화 등)·날짜·From 메타 행 + 제목 + 본문 2줄 말줄임 + "더 보기"
- 히스토리 상단에 상태 셀렉트 풀폭 + 최초/마지막 컨택일 요약 카드를 두어
  "지금 어떤 상태이고 언제 마지막으로 연락했나"를 먼저 보여줌

## 클래스 제작 현황 트래킹 (2026-07, 목록+상세)

- 제작 단계(계약→오픈 6단계) 진척은 "N/6 · 단계명" 태그 칩으로 표기
- 단계별 기준 소요일을 두고, 초과분을 "N일 초과" 경고 뱃지로 표기해 컨택 우선순위를 만듦
- 재촉↔응답 히스토리에서 무응답 상태는 타임라인에 경고 항목으로 승격시켜
  다음 액션("계약 유지 의사 확인 필요")까지 제안
- 통계 스트립에 완주율(착수 대비 오픈 도달)을 넣고, 담당 매니저 필터가
  통계·차트·테이블을 함께 재계산하게 함 ("전체 성과 vs 내 담당" 전환)
