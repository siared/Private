출처: Figma `Admin` 파일 (aPrJ7mLNIjsFQHXE6G3Wii, node 14919-97072)
"레이아웃 패턴" 5종 + "화면 타입별 활용 예시" 텅 빈 샘플 3종에서 추출.
추출일: 2026-07-03, 빈 샘플 기준 재실측: 2026-07-07. 모든 수치는 1920px 데스크톱 기준.

> **가이드의 목적**: 반드시 지켜야 하는 법이 아니라, 활용 가능한 웬만한 상황에서는
> 지켜서 화면을 패턴화하기 위한 것이다. 유저에게 익숙한 UX를 주고 작업자가 효율적으로
> 일하기 위함이므로, 화면 특성상 벗어나는 게 나으면 벗어나되 그 이유를 결과물에 명시한다.
>
> 이 문서의 범위는 **레이아웃 구조와 UI 스타일**(치수·패딩·radius·테두리·타이포)까지다.
> 그 틀에 **어떤 내용물**(데이터·기능·셀 구성)을 담을지는 화면 목적에 맞게 정한다.
> 실제 화면에서 내용물을 응용한 맥락은 `docs/reference-examples.md`(참고용) 참고.

## 1. 전체 셸 (App Shell)

```
┌────────────────────────────────────────────────┐
│ 헤더 72px (풀폭) — 좌: 토글·로고 / 우: 스토어·상태·아바타 │
├─────────┬──────────────────────────────────────┤
│ 사이드바   │  콘텐츠 영역 1680px (좌우 패딩 40px)       │
│ 240px    │  ┌ 페이지 헤더                           │
│ (흰 배경)  │  └ 본문                                │
└─────────┴──────────────────────────────────────┘
```

| 항목 | 값 |
|---|---|
| 기준 뷰포트 | 1920px |
| 헤더 | 높이 72px, **풀폭**(사이드바 위가 아니라 화면 전체). 흰 배경 + 하단 헤어라인(outline1) |
| 사이드바 | 폭 240px, 헤더 아래 좌측 고정. **흰 배경**(다크 아님) + 우측 헤어라인 |
| 콘텐츠 영역 | 1680px (1920−240), 좌우 패딩 40px (`Layout/Content Area/Padding X`) |

사이드바 메뉴: 섹션 라벨(12px 회색, 높이 40px) + 아이템(높이 44px, 아이콘 20×20 + 라벨 14px).
활성 항목은 연회색(#F3F3F3) 라운드 하이라이트.

## 2. 콘텐츠 폭 패턴 5종

본문 골격은 기본적으로 아래 5종 중 하나를 쓴다. 특별한 이유 없이 새 폭을 만들지 않는다.

| 패턴 | ContentsArea | 실제 콘텐츠 폭 | 주 용도 |
|---|---|---|---|
| 1열 full-width | 1680 (전체) | 1600 | 대시보드 테이블 리스트 |
| 1열 max-1312 | 1312, 중앙 정렬 | 1232 | 일반 콘텐츠 |
| 1열 max-720 | 720, 중앙 정렬 | 640 | 입력 폼 |
| 2열 8:4 | 1312, 중앙 정렬 | 808 + 거터 40 + 384 | 메인 + 보조 패널 |
| 2열 4:8 | 1312, 중앙 정렬 | 384 + 거터 40 + 808 | 요약 + 메인 (상세 페이지) |

- 좌우 패딩 40은 ContentsArea 폭 **안쪽**에 포함된다. CSS 기준:
  `max-width: 1312px; margin: 0 auto; padding: 0 40px; box-sizing: border-box`
- 검산: full-width 40+1600+40=1680 / max-1312 40+1232+40=1312 / max-720 40+640+40=720 /
  2열 40+808+40(거터)+384+40=1312
- ※ 상세 예시 실측에선 좌 컬럼이 `flex 1, max-width 420`으로 잡혀 있다 —
  고정 384 대신 max-420 유동도 허용 범위

## 3. 페이지 헤더 (공통)

- 콘텐츠 최상단, 상하 패딩 20 (`between-card-lg`). 템플릿 프레임 실측 전고 86
  (서브타이틀 등 구성에 따라 66~86)
- 좌측: (하위 페이지면) **뒤로가기 IconButton sm**(30×30 박스) + gap 4 +
  **타이틀 20/26 Bold** (자간 −1.8%)
  - 타이틀 우측에 Badge(neutral, md) 메타 병기 가능, 타이틀 아래 서브타이틀
    14/18 Regular(#616161) 가능 (상세 페이지 샘플)
- 우측: 버튼 그룹, gap 8 — **ContainedButton md** 사용.
  primary(#FF5D00)는 화면당 최대 1개(맨 오른쪽), 나머지는 tertiary
- **폼의 [취소 tertiary][저장 primary]도 여기 우측에 배치한다 (하단 고정 액션바를 쓰지 않는다)**

## 4. 페이지 타입별 골격 + UI 스타일 (빈 샘플 실측)

Figma "화면 타입별 활용 예시" 텅 빈 샘플 3종 기준. **구조와 스타일은 아래를 따르고,
각 틀에 담을 내용물(컬럼·필드·카드 항목)은 화면 목적대로 정한다.**

### 4.1 대시보드 테이블 리스트 — `1열 full-width`

위에서 아래로: 페이지 헤더 → 통계 바 → (간격 28) → 테이블 블록

**통계 바** (선택): 카드 1장을 세로 Divider로 분할한 스트립
- 테두리 outline1(0.05), radius **8**, 흰 배경
- 첫 칸: 기간 선택 — 캘린더 아이콘 + 라벨 12/16 Medium + ▾, 내용만큼(hug)
- 스탯 칸: 균등 분할(flex 1), 패딩 16, 내부 세로 gap 8,
  라벨 **13/18 Medium**(onView1) + 수치 **24/32 Bold** (자간 −2%)
- 칸 전체가 hover/클릭 가능(Pressable)

**테이블 블록**: 요소 사이 세로 간격 **12**
1. 검색 행 (h 38): TextField **400×38** 좌측 배치
2. 필터 칩 행 (h 38): 멀티셀렉트 필터 칩(폭 hug, ~138+) 나열 / 우측 끝 텍스트(Ghost) 버튼들
3. 테이블: 헤더 행 **44** (컬럼명 13px 회색) / 데이터 행 **44**, 행 사이 헤어라인
   (지브라 없음), 행 전체가 클릭 영역(Pressable), 우측 끝 더보기(⋯) 컬럼 52px
4. 푸터 행 (h 38): 좌 "총 N 개" / 우 페이지당 행 수 셀렉트 + Pagination
   (현재 페이지 검정 원형)

### 4.2 입력 폼 — `1열 max-720`

- 페이지 헤더: ← + 타이틀 / 우측 [취소 tertiary] [저장 primary]
- 본문: 폭 640, **섹션 카드 스택, 카드 간 28**

**섹션 카드**: 흰 배경, 테두리 **outline2(rgba(0,0,0,0.1))**, radius **16**, overflow clip
- 카드 헤더: 패딩 20, 타이틀 **14/18 Bold**(Title.level7),
  (선택) 설명 14/20 Regular(onView2), (선택) 우측 텍스트 버튼 그룹(gap 16)
- 카드 본문: 헤더와 구분선 outline1, 패딩 20,
  **필드 행 간 세로 16 / 한 행 안 필드 가로 gap 12** (1~4열 조합 자유)
- 필드: 라벨 상단(Label alignment=top) + TextField **lg**, 플레이스홀더 회색

### 4.3 상세 페이지 — `2열 4:8`

- ContentsArea 세로 gap 16 (페이지 헤더 ↔ 본문)
- 페이지 헤더: ← + 타이틀(+Badge 메타, 서브타이틀 가능) / 우측 버튼 그룹
  (tertiary 들 + 필요시 primary 1개)
- **좌 요약 열** (flex 1, max 420): **정보 카드 스택, 카드 간 20**
  - 정보 카드: 흰 배경, 테두리 outline2(0.1), radius **8** (폼 카드 16과 다름 — 컴팩트 카드)
  - 카드 헤더: 패딩 20, 타이틀 14/18 Bold, 우측 유틸 액션 = **GhostButton sm** (gap 16)
  - 카드 본문: 좌우 패딩 12, 하단 패딩 12, **List Item(vibrant-ui) 반복**
- **우 메인 열** (flex 1): 세로 gap 16
  - 섹션 타이틀 행: 타이틀 **18/22 Bold**(Title.level5) / 우측 **OutlinedButton md**
  - 그 아래는 자유 콘텐츠 영역 (화면 목적에 맞게 구성)

### 4.4 차트 중심 대시보드 — 전용 템플릿 없음

통계 바 + 필요시 `2열 8:4`로 구성. 신규 구성은 사용자에게 확인.

## 5. 공통 스타일 원칙

- **플랫 & 뉴트럴**: 전체가 흰 배경, 그림자 없음.
  카드 테두리는 **outline2(rgba(0,0,0,0.1))**, 카드 내부 구분선·행 구분은 outline1(0.05)
- 카드 radius 구분: **콘텐츠 섹션 카드 16** (폼 등) / **컴팩트 정보 카드·통계 바 8**
- 버튼 위계: 페이지 헤더 = ContainedButton md (primary/tertiary) /
  섹션 액션 = OutlinedButton md / 카드 헤더 유틸 = GhostButton sm / 뒤로가기 = IconButton sm
- **primary 오렌지(#FF5D00)는 화면당 핵심 CTA 1개에만**
- 상태 표현: 색 점 + 텍스트 라벨 동반 (색만으로 구분하지 않음)
- 개인정보(이름·이메일·전화)는 기본 마스킹, "마스킹 해제" 액션으로 노출
- 반응형: 데스크톱 1920 기준. 축소 시 규칙은 시안에 없음 — TODO(브랜드)
- 날짜 표기 실측: 테이블 `2026.01.01`, 상세 요약 `2025년 8월 1일`
- 구현이 vibrant-ui를 쓸 수 있으면 대응 컴포넌트를 우선 사용:
  Table(검색·필터·페이지네이션 포함), TextField, Label, Filter Chip, List/List Item,
  List Header, ContainedButton/OutlinedButton/GhostButton/IconButton, Badge, Divider, Pagination
