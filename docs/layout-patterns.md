## 1. 전체 셸 (App Shell)

```
┌────────────────────────────────────────────────┐
│ 헤더 72px (풀폭) — 좌: 토글·로고 / 우: 스토어·상태·아바타 │
├─────────┬──────────────────────────────────────┤
│ 사이드바   │  콘텐츠 영역 1680px (좌우 패딩 40px)       │
│ 240px    │  ┌ 페이지 헤더 86px                      │
│ (흰 배경)  │  └ 본문                                │
└─────────┴──────────────────────────────────────┘
```

| 항목 | 값 |
|---|---|
| 기준 뷰포트 | 1920px |
| 헤더 | 높이 72px, **풀폭**(사이드바 위가 아니라 화면 전체). 흰 배경 + 하단 헤어라인 |
| 헤더 좌측 | 사이드바 토글 아이콘 + 로고 (CLASS101 Admin) |
| 헤더 우측 | 스토어 선택 드롭다운("한국 스토어 ▾") + 상태 칩(녹색 점 "응대 중", 연녹색 필) + 프로필 아바타 |
| 사이드바 | 폭 240px, 헤더 아래 좌측 고정. **흰 배경**(다크 아님) + 우측 헤어라인 |
| 콘텐츠 영역 | 1680px (1920−240), 좌우 패딩 40px (`Layout/Content Area/Padding X`) |

### 사이드바 메뉴 구조
- 섹션 라벨(12px 회색 캡션, 높이 40px) + 메뉴 아이템 반복
- 메뉴 아이템: 높이 44px, 좌측 아이콘 20×20 + 라벨 14px, 내부 들여쓰기 12+8px
- 활성 항목: 연회색(#F3F3F3) 배경의 라운드 하이라이트
- 하위 메뉴가 있으면 우측 chevron, 펼치면 2뎁스 항목이 들여쓰기로 노출 (기본 접힘)
- 예시 섹션: 고객관리 / 101+ Studio / 크리에이터 센터 / 상품 및 클래스 관리

## 2. 콘텐츠 폭 패턴 5종

본문 골격은 반드시 아래 5종 중 하나를 쓴다. (콘텐츠 폭 = ContentsArea에서 좌우 패딩 40 제외한 실폭)

| 패턴 | ContentsArea | 실제 콘텐츠 폭 | 주 용도 |
|---|---|---|---|
| 1열 full-width | 1680 (전체) | 1600 | 테이블 목록 |
| 1열 max-1312 | 1312, 중앙 정렬 | 1232 | 일반 콘텐츠 |
| 1열 max-720 | 720, 중앙 정렬 | 640 | 입력 폼 |
| 2열 8:4 | 1312, 중앙 정렬 | 808 + 거터 40 + 384 | 메인 + 보조 패널 |
| 2열 4:8 | 1312, 중앙 정렬 | 384 + 거터 40 + 808 | 요약 + 메인 (상세 페이지) |

- 카드(섹션) 간 세로 간격: 28px

## 3. 페이지 헤더 (공통)

- 높이 86px, 콘텐츠 최상단 (타이틀 텍스트는 상단에서 28px 지점)
- 좌측: (하위 페이지인 경우) ← 뒤로가기 아이콘 + 페이지 타이틀 20px Bold
- 우측: 버튼 그룹 — primary(오렌지 필) 버튼은 화면당 최대 1개 + secondary(흰 배경 아웃라인) 버튼
- **폼 화면의 [취소][저장]도 여기 우측에 배치한다. 하단 고정 액션바를 쓰지 않는다.**

## 4. 페이지 타입별 골격

### 4.1 목록 (테이블 리스트) — `1열 full-width`

위에서 아래로:
1. **페이지 헤더** — 타이틀 / 우측: secondary("CSV 다운로드" 등) + primary("○○ 추가")
2. **통계 바** (선택) — 카드 1개를 세로 구분선으로 분할한 스트립.
   첫 칸: 기간 선택("최근 1개월 ▾") / 이후 칸: 상태별 스탯 = 상태색 점 + 라벨 13px + 수치 24px Bold
3. **테이블 블록** (내부 요소 간격 12px):
   - 검색 인풋 행 (높이 38px, 플레이스홀더 + 우측 돋보기 아이콘)
   - 필터 칩 행 (높이 38px): 드롭다운 필 칩("카테고리 ▾" 등 아웃라인 필) 나열, 우측 끝 "↻ 초기화"
   - 테이블
   - 푸터 행 (높이 38px): 좌 "총 N 개" / 우 "페이지당 행 수: 10 ▾" + ‹ 1 2 3 4 5 › (현재 페이지는 검정 원형)

테이블 규칙:
- 헤더 행: 좌측 끝 전체 선택 체크박스, 컬럼명 13px 회색, 정렬 가능 컬럼은 ↓↑ 아이콘
- 데이터 행: 높이 약 53px, 행 사이 헤어라인 구분 (지브라 스트라이프 없음)
- 셀 유형: 일반 텍스트 14px / 상태 셀렉트(색 점 + 라벨 + ▾, 아웃라인 필) /
  태그 칩(연회색 필, "Youtube 32k" "+2" 등) / 경고 뱃지(연빨강 배경 + 빨강 텍스트, "3개월+ 지남" 등)
- 값이 없으면 회색으로 "없음"

### 4.2 입력 폼 (등록/수정) — `1열 max-720`

1. **페이지 헤더** — ← + 타이틀 / 우측: [취소](secondary) [저장](primary)
2. **섹션 카드** 스택 (간격 28px) — 카드 = 흰 배경 + 헤어라인 아웃라인 + radius 16:
   - 카드 타이틀 행("기본 정보" 16px Bold) + 헤어라인 구분선 + 필드 목록
3. 필드 규칙:
   - 라벨(14px) 인풋 상단 배치, 인풋 높이 약 38px, radius 8, 헤어라인 테두리, 플레이스홀더 회색
   - 반복 가능 필드: 인풋 아래 "+ 이메일 추가" 같은 텍스트 버튼
   - 전화번호: 000 - 0000 - 0000 3분할 인풋
   - 카테고리: 1차/2차/3차 캐스케이드 컬럼 셀렉터 (열마다 옵션 리스트 + chevron)
   - 담당자 지정: "나에게 할당" 칩 버튼 + 돋보기(검색) 아이콘 버튼
4. **추가형 섹션 카드**: 타이틀에 카운트 "활동 채널 (0)" + 설명 캡션 / 우측 "+ 추가" 버튼.
   항목을 추가하면 카드 안에 목록이 쌓이는 구조

### 4.3 상세 페이지 — `2열 4:8`

1. **페이지 헤더** — ← + 대상 식별자 타이틀(개인정보는 마스킹 "하이****") / 우측: "✏ ○○ 수정" (secondary 아웃라인. 상세에서는 primary 없음)
2. **좌측 4fr (384px): 요약 카드 스택** (간격 28px):
   - "기본 정보" 카드: 헤더 행(타이틀 + 유틸 액션 "마스킹 해제" 등) / 본문은 라벨:값 2열 행
     (라벨 회색 14px 좌측 고정폭, 값 우측). 값이 여러 개면 세로로 쌓고 "대표" 같은 칩 동반
   - 연관 엔티티 카드: 타이틀에 카운트 "활동 채널 (2)", 행마다 라벨 + 링크 + 캡션(팔로워 수) + 외부링크 아이콘
   - 빈 카드: "크리에이터 계정 (0)" + 헤더 액션("🔗 계정 연결") + 본문은 회색 한 줄 "연결된 계정 없음"
3. **우측 8fr (808px): 메인 콘텐츠**:
   - 섹션 타이틀 행: "컨택 히스토리 (2)" 20px Bold / 우측 "+ 히스토리 추가" (secondary)
   - 상태 카드: 상태 셀렉트(색 점 + "컨택 중" + ▾) 풀폭 + 구분선 + 라벨:값 요약(최초/마지막 컨택일, 경고 뱃지 동반 가능)
   - 타임라인 목록: 좌측 파란 점 + 세로 연결선 / 항목 = 메타 행(유형 칩 "이메일", 태그, 날짜, From:)
     + 제목 14px Bold + 본문 2줄 말줄임 + "더 보기"

### 4.4 대시보드

전용 템플릿 없음. 목록 페이지의 **통계 바** 패턴을 KPI 행으로 쓰고,
차트/패널이 필요하면 `2열 8:4`로 구성한다. (신규 구성 시 사용자에게 확인)

## 5. 공통 스타일 원칙

- **플랫 & 뉴트럴**: 전체가 흰 배경. 카드는 그림자 없이 헤어라인 아웃라인 + radius 16
- **primary 오렌지(#FF5D00)는 화면당 핵심 CTA 1개에만** (목록의 "추가", 폼의 "저장"). 나머지는 아웃라인 버튼
- 상태 표현: 색 점 + 텍스트 라벨 동반 (색만으로 구분하지 않음)
  - 예시 매핑: 회색=미시작/드랍, 파랑=진행 중, 오렌지=미팅 진행, 노랑=준비, 초록=완료, 빨강=경고/에러
- 개인정보(이름·이메일·전화)는 기본 마스킹, "마스킹 해제" 액션으로 노출
