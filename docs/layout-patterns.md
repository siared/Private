## 2. 페이지 타입

새 화면은 반드시 아래 4가지 중 하나를 골격으로 삼는다.

### 2.1 목록 (List / Table)
가장 빈번한 타입. 위에서 아래로:
1. **페이지 타이틀 행** — 좌: 타이틀(+건수), 우: 주요 액션 버튼(등록 등, 최대 2개)
2. **필터 바** — 검색 인풋 + 셀렉트 필터들, 우측에 초기화. 필터 4개 초과 시 "상세 필터" 접기
3. **테이블** — 체크박스 열(일괄 작업 필요 시) / 정렬 가능 헤더 / 행 클릭 시 상세 이동
4. **페이지네이션** — 하단 우측(또는 중앙), 페이지당 행 수 셀렉트 동반
- 행 단위 액션은 마지막 열에 아이콘 버튼 또는 케밥(⋮) 메뉴
- 빈 상태: 일러스트 없이 안내 문구 + 주요 액션 버튼

### 2.2 상세 (Detail)
1. **상단 바** — 뒤로가기 + 타이틀(대상 식별자), 우측에 수정/삭제 등 액션
2. **요약 카드** — 핵심 필드를 라벨:값 그리드(2~3열)로
3. **탭 또는 섹션 카드** — 연관 정보(이력, 관련 목록 등)를 탭으로 분리. 3개 이하면 세로 섹션 카드도 허용

### 2.3 폼 (등록/수정)
1. **상단 바** — 뒤로가기 + 타이틀
2. **폼 본문** — 단일 컬럼, 최대 폭 640~720px. 섹션이 많으면 카드로 그룹핑
3. **하단 액션 바** — 우측 정렬: [취소] [저장(primary)]. 긴 폼이면 하단 고정(sticky)
- 라벨은 인풋 상단 배치, 필수 표시는 라벨 옆 `*`
- 유효성 오류는 해당 필드 하단에 인라인 표시
- 파괴적 동작(삭제 등)은 확인 모달 필수

### 2.4 대시보드
1. **KPI 스탯 카드 행** — 3~4개, 등폭 그리드
2. **차트 영역** — 12컬럼 그리드 기준 8+4 또는 6+6 분할
3. **최근 항목 테이블** — 하단, "전체 보기" 링크 포함
- 기간 필터는 페이지 우상단에 공통 배치

## 3. 공통 컴포넌트 규칙

- **모달**: 폭 480px(확인용) / 640px(폼 포함). 제목 + 본문 + 우측 정렬 액션
- **토스트**: 저장/삭제 성공 피드백. 우상단, 3초 후 자동 닫힘
- **상태 뱃지**: 색상만으로 구분하지 않고 텍스트 라벨 동반
