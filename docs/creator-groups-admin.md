# 크리에이터 그룹 관리 — 어드민 화면 디자인

> 시안: [`mockups/creator-groups.html`](../mockups/creator-groups.html) (브라우저에서 바로 열어 인터랙션 확인 가능)

## 1. 화면 목적

크리에이터 소싱 대상들을 **그룹**으로 묶어 관리하고, 그룹 단위로 두 가지 실행 액션을 수행하는 화면.

1. **캠페인 만들기** — 선택한 그룹(들)의 크리에이터를 대상으로 캠페인 초안 생성
2. **템플릿 메일 발송** — 미리 등록된 메일 템플릿을 골라 그룹 전체에 발송

## 2. 정보 구조 (IA)

```
사이드바
├── 대시보드
├── 소싱
│   ├── 크리에이터        (개별 크리에이터 DB)
│   └── 그룹 관리  ★ 본 화면
├── 실행
│   ├── 캠페인
│   ├── 메일 템플릿
│   └── 발송 리포트
└── 설정
```

본 화면(그룹 관리)은 소싱(크리에이터 DB)과 실행(캠페인·메일)을 잇는 허브 역할.

## 3. 화면 구성

### 3-1. 요약 스탯 (상단)
운영자가 화면 진입 즉시 현황을 파악하도록 4개 타일: 전체 그룹 수 / 등록 크리에이터 수 / 진행 중 캠페인 / 이번 주 메일 발송(오픈율·회신율 포함).

### 3-2. 툴바
- 검색 (그룹명·태그)
- 필터: 플랫폼, 상태
- 정렬: 최근 활동순(기본) / 크리에이터 많은순 / 이름순 / 생성일순

### 3-3. 그룹 목록 테이블
| 컬럼 | 내용 |
|---|---|
| 체크박스 | 다중 선택 → 하단 선택 액션 바 노출 |
| 그룹 | 그룹명(상세 링크) + 태그 칩 |
| 크리에이터 | 인원 수 (tabular-nums) |
| 플랫폼 구성 | YT/IG/TT 비율 미니 스택 바 + 수치 |
| 상태 | 활성 / 구성 중 / 보관 (컬러 필) |
| 담당자 | 그룹 오너 |
| 최근 활동 | 상대 시간 + 마지막 액션 요약 |
| 액션 | 행 단위 바로가기: 메일 발송 / 캠페인 만들기 / 더 보기 |

### 3-4. 선택 액션 바 (핵심 인터랙션)
행을 1개 이상 체크하면 화면 하단 중앙에 플로팅 바 노출:

```
[ N개 그룹 선택 · 크리에이터 M명 ] | [템플릿 메일 발송] [캠페인 만들기(primary)] [선택 해제]
```

- 여러 그룹을 합쳐 하나의 캠페인/발송 대상으로 만드는 것이 주 시나리오
- 행 액션 아이콘은 단일 그룹 대상의 빠른 진입점 (같은 모달을 해당 그룹만으로 오픈)

## 4. 주요 플로우

### 4-1. 새 그룹 만들기 (모달)
그룹명 / 설명 / 주요 플랫폼 / 팔로워 범위(나노~메가) / 태그.
소싱 조건을 지정하면 조건에 맞는 크리에이터를 자동 제안(후속 기능).

### 4-2. 그룹 → 캠페인 만들기 (모달)
- 상단에 **대상 그룹 요약 박스**: 그룹별 인원 + 합계, 중복 크리에이터는 1명으로 계산됨을 명시
- 입력: 캠페인명 / 유형(제품 협찬·유료 광고·공동 기획·앰배서더) / 예산(선택) / 기간
- 생성 시 **초안 상태**로 저장 → 캠페인 탭에서 브리프·섭외를 이어서 진행

### 4-3. 그룹 → 템플릿 메일 발송 (와이드 모달, 2단)
- 좌: 템플릿 리스트 (템플릿명 + 용도·성과 메타: 오픈율/회신율) + "템플릿 관리로 이동"
- 우: **실시간 미리보기** (제목 / 발신자 / 본문, 치환 변수 하이라이트)
- 변수: `{크리에이터명}` `{채널명}` `{캠페인명}` — 발송 시 수신자별 자동 치환
- 안전장치:
  - 이메일 없는 크리에이터 자동 제외 안내
  - 수신자 수 확정 표기 ("중복·이메일 없음 제외 후 확정")
  - **테스트 발송** 버튼 (본인 계정으로) → 그다음 **지금 발송**
- 발송 후: 발송 대기열 등록 토스트 → 발송 리포트에서 추적

## 5. 디자인 토큰

### 컬러
| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--bg` | `#F6F7F4` | `#151A17` | 페이지 그라운드 (웜 그린 뉴트럴) |
| `--surface` | `#FFFFFF` | `#1D2420` | 카드·테이블·모달 |
| `--ink` | `#1B2320` | `#E7ECE8` | 본문 텍스트 |
| `--accent` | `#0B7A63` | `#3AA88D` | 주요 액션 (딥 켈프 그린) |
| `--good / --warn / --danger` | `#1A8A52` / `#A8730F` / `#BF4538` | 밝기 보정 | 상태 시맨틱 (액센트와 분리) |
| `--chip-yt / ig / tt` | `#B8483D` / `#A05A9C` / `#3D7D8A` | 밝기 보정 | 플랫폼 구성 바 |

### 타이포
- 패밀리: `Pretendard` → `Apple SD Gothic Neo` → `Malgun Gothic` 시스템 스택
- 스케일: 페이지 타이틀 21 / 모달 타이틀 16 / 본문 14→13 / 캡션·메타 12→11
- 숫자 컬럼: `font-variant-numeric: tabular-nums`
- 테이블 헤더: 11px, uppercase, letter-spacing `.06em`

### 기타
- 라운드: 카드 10px / 모달 14px / 버튼·인풋 8px
- 라이트·다크 듀얼 테마: 토큰 레벨에서 `prefers-color-scheme` + `data-theme` 오버라이드
- `prefers-reduced-motion` 대응 (선택 바 트랜지션·토스트 애니메이션 제거)
